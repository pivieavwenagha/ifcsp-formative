# Quiz plan for implementation

## Notes

- This program will run in a while loop, until the user writes 'stop' at the end.
- Each mode will have 5 questions
- Beginner mode has basic addition and subtraction
- Medium mode has multiplication and division
- Hard mode has combination problems that require BODMAS to solve

## Tasks

1. Initialise variables - name, mode, game_run, points, list of questions, list of corresponding answers (completed)
2. Menu screen where the user chooses easy, medium or difficult mode (completed)
3. Create subroutines for each mode of the game (complete)
    - If answer is correct, add a point. Else, do nothing (complete)
4. Make first menu more intuitive by explaining that there are 5 questions.
5. Edit README
6. Create Technical Documentation
